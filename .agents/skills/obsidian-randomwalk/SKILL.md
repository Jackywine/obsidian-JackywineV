# Obsidian 随机漫步 Skill

在 Jackywine 大人的知识库里像漫步在森林中一样，不按地图、不设目的地，让 wikilink 之间的连接带你发现被遗忘的角落和意想不到的关联。

## 漫步模式

### 模式 1：🎲 纯随机 —「随便看看」「随机漫步」

从全部笔记中完全随机选一篇，没有任何偏向。

**触发词**：`随便看看`、`随机漫步`、`random`、`来一篇`

**实现步骤**：
1. 用 `file_search` 列出 vault 中所有 .md 文件（排除 .trash/、.agents/、Templates/、.obsidian/、copilot/、Claudian/、Clippings/、attachment/）
2. 用 `exec_shell` 运行 Python oneliner 随机选 1 个：
   ```bash
   python3 -c "import random; print(random.choice(open('/tmp/vault_notes.txt').read().splitlines()))"
   ```
3. 用 `read_file` 读取该笔记前 30 行，展示标题和开头内容
4. 列出该笔记的 wikilink 出边（最多 8 个），提示用户「要不要顺着这个链接继续跳？」

**输出格式**：
```
🎲 随机漫步来到：[[笔记名]]

📝 开头预览：
[前几行内容...]

🔗 从这里可以跳去：
- [[链接1]]
- [[链接2]]
...

要不要继续跳？说「再跳一次」就好哦～
```

### 模式 2：🔗 Wikilink 跳跃 —「跳一跳」「再跳一次」

从当前/指定笔记出发，随机选一个 wikilink 跳转到目标笔记。支持连续跳跃。

**触发词**：`跳一跳`、`再跳一次`、`从 [[xxx]] 开始跳`、`跟着链接走`

**实现步骤**：
1. 确定起点笔记（用户指定 或 上一次漫步的终点 或 随机选一篇）
2. 用 `grep_files` 提取起点笔记中的 wikilink：
   ```
   pattern: "\[\[([^\]|#]+)"
   path: "起点笔记.md"
   ```
3. 过滤掉图片嵌入（`![[`）、音频嵌入、PDF 嵌入，只保留笔记链接
4. 去重后用 Python `random.choice` 选目标
5. 用 `read_file` 读取目标笔记前 30 行
6. 记录跳跃路径：`起点 → 目标`

**连续跳跃**：用户说「再跳一次」时，以当前笔记为起点重复步骤 2-6。

**路径追踪**：每次跳跃记录路径，最终显示：
```
🗺️ 漫步路径：
[[起点]] → [[跳1]] → [[跳2]] → [[终点]]

📝 [[终点]] 的摘要：
[内容...]
```

### 模式 3：🏷️ 标签漫步 —「按标签漫步」「#设计 随便看看」

在具有相同标签的笔记间漫步。标签来源：frontmatter `tags:` 和行内 `#标签`。

**触发词**：`按标签漫步`、`#设计 随便看看`、`同标签跳一跳`、`标签：AI`

**实现步骤**：
1. 确定标签（用户指定 或 从当前/随机笔记的标签中随机选）
2. 用两次 `grep_files` 搜索：
   - Frontmatter 格式：`pattern: "^tags:.*标签名"`（需要处理 YAML 列表格式）
   - 行内格式：`pattern: "#标签名\b"`
3. 合并去重候选笔记列表
4. 随机选一篇，`read_file` 展示内容
5. 提示同标签下还有多少篇

**输出格式**：
```
🏷️ 标签 [#AI] 下共有 47 篇笔记，随机漫步来到：

[[笔记名]]
📝 [内容预览...]

🏷️ 同标签还有：[列出 3-5 个随机候选]
要继续在 #AI 里逛吗？
```

### 模式 4：🔙 反向链接漫步 —「谁链到了这」「反链跳」

找出所有引用了当前笔记的笔记（反向链接 / backlinks），随机跳转到其中一篇。这是最有趣的模式——你看到的是「谁在悄悄关联这个话题」。

**触发词**：`谁链到了这`、`反链跳`、`backlinks`、`从反向链接跳`

**实现步骤**：
1. 确定当前笔记
2. 用 `grep_files` 全库搜索引用了当前笔记的文件（排除自引用）：
   ```
   pattern: "\[\[当前笔记名(\]\]|\||#)"
   ```
3. 去重后随机选一篇
4. `read_file` 展示该笔记中提到当前笔记的上下文（context_lines: 3）
5. 展示跳跃路径

**输出格式**：
```
🔙 [[当前笔记]] 被 12 篇笔记引用，随机漫步来到：

[[反链笔记1]]
📍 它这样提到 [[当前笔记]]：
> [上下文内容...]

🗺️ 反向跳跃路径：[[当前笔记]] ← [[反链笔记1]]
```

### 模式 5：🗺️ 两跳惊喜 —「两跳」「惊喜漫步」

从当前笔记出发，跳两次 wiki link，展示起点和终点的对比。两跳之后通常能到达一个和起点「八竿子打不着」的领域，制造惊喜。

**触发词**：`两跳`、`惊喜漫步`、`serendipity`、`远走高飞`

**实现步骤**：
1. 起点 → 随机 wikilink → 中间站
2. 中间站 → 随机 wikilink → 终点
3. 对比起点和终点的标签/主题差异
4. 展示完整路径

**输出格式**：
```
🗺️ 两跳惊喜！

起点：  [[设计流程已死，设计师万岁]]  (#设计 #AI)
  ↓ 第一跳
中间：  [[Figma]]  (#工具 #设计)
  ↓ 第二跳
终点：  [[3Blue1Brown]]  (#数学 #教育)

🎉 从「设计方法论」跨到了「数学可视化」！
这俩有什么关系？也许 [[3Blue1Brown在 figma 大会上的演讲]] 能告诉你～
```

### 模式 6：🏝️ 冷门发现 —「发现冷门」「孤岛笔记」

找出连接度最低的笔记——wikilink 出边 + 被引用次数 < 阈值（默认 3）。这些是被遗忘的角落，往往藏着宝藏。

**触发词**：`发现冷门`、`孤岛笔记`、`被遗忘的笔记`、`orphan`

**实现步骤**：
1. 全库扫描所有 .md 笔记
2. 对每篇笔记计算连接度：
   - 出边数：该笔记中 wikilink 的数量
   - 入边数：其他笔记引用它的次数
   - 连接度 = 出边数 + 入边数
3. 筛选连接度 < 3 的笔记
4. 随机选 1-3 篇展示
5. 展示每篇的开头内容

**优化**：由于 471 篇笔记规模不大，用 Python 脚本一次性计算全库连接度矩阵更高效：
```python
import os, re, json, random
vault = "/Users/jackywine/Documents/Jackywine2025_Obsidian_Vault"
notes = {}
# ... 扫描所有 .md，提取 wikilink，构建邻接表 ...
```

**输出格式**：
```
🏝️ 发现 23 座「孤岛」笔记，随机打捞 3 篇：

1. [[1997]]
   📝 只有一行：1997 年发生了什么？
   🔗 出边 0 | 被引 0 — 完全孤岛！

2. [[1986年十万美元一稿不改的LOGO设计师]]
   📝 #乔布斯 #人物/保罗兰德 #LOGO
   🔗 出边 0 | 被引 1

3. [[毕达哥拉斯主义符号]]
   📝 嵌入了一张图片，链接了 [[毕达哥拉斯]]
   🔗 出边 1 | 被引 0

💡 这些笔记在等你回来看看呢～
```

## 通用规则

### 笔记白名单 / 黑名单

**排除目录**（不参与漫步）：
- `.trash/` — 垃圾桶
- `.agents/` — Agent skill 内部文件
- `.obsidian/` — Obsidian 配置
- `Templates/` — 模板
- `copilot/` — Copilot 缓存
- `Claudian/chat-archives/` — 聊天归档
- `.Codex/` — Codex 内部

**排除文件**：
- 文件名匹配 `*.canvas`（画布文件）
- 文件名匹配 `*.base`（数据库文件）
- `1ndex.md` 和 `1nbox.md` 和 `1Navi.md` 可作为起点但建议不作为随机目的地（它们是元笔记）

### Wikilink 解析规则

Obsidian wikilink 格式多样：
```
[[Note Name]]
[[Note Name.md]]
[[Note Name|Display Text]]
[[Note Name#Heading]]
[[Note Name#^block-id]]
![[image.png]]          ← 嵌入，不参与漫步
![[Note Name]]          ← 嵌入笔记，可参与漫步（但优先级低）
```

提取笔记名时，统一去掉 `|` 后面的显示文本、`#` 后面的锚点、`.md` 后缀。

### 路径记忆

在同一次对话中，`obsidian-randomwalk` 维护一个**漫步路径栈**：
- 起点 → 跳1 → 跳2 → ... → 当前
- 用户说「回去」时，沿路径栈回退一步

### 笔记预览

`read_file` 读取笔记时：
- 默认取前 30 行（约 2000 字符）
- 跳过 frontmatter（`---` 块）
- 优先展示第一个非空段落

## 注意事项

1. **性能边界**：冷门发现模式需全库扫描 ~471 篇笔记，预计 3-5 次 `grep_files` 调用。对于更大的库（>2000 篇），建议用 `exec_shell` + Python 脚本一次性处理。
2. **wikilink 歧义**：`[[AI]]` 可能匹配到 `[[AI 安全]]`、`[[AI 电影]]` 等，grep 时用词边界 `\[\[AI\]\]` 精确匹配。
3. **同名图片**：`![[Snipaste_xxx.png]]` 要过滤掉，不算 wikilink 跳转目标。
4. **断头链接**：wikilink 指向的笔记可能不存在（紫色链接），跳过或提示用户。
5. **尊重隐私**：不读取标记为 `private: true` 的 frontmatter 笔记（如有此约定）。
